# Architectural Decision Records (ADR) — Portfólio Profissional (Analista de IA)

## ADR-001: Definição da Stack & Padrão de Comunicação API-First
- **Data:** 2026-11-07T06:45:03.748Z
- **Status:** Aceito
- **Contexto:** Necessidade de entrega ágil, código modular e desacoplamento entre frontend e backend.
- **Decisão:** Arquitetura API-First com contratos RESTful JSON documentados em SPEC.md e interface com cobertura obrigatória dos 4 estados visuais.
- **Consequências:** Frontend e backend podem ser desenvolvidos e testados de forma independente.
